Управление данными

Статусы хранятся локально через localStorage. Для демонстрации используйте только несекретную информацию. История может исчезнуть при очистке данных браузера.

Как рассчитывается индекс

+30 — нереалистичная / гарантированная доходность
+25 — внесение денег для участия
+20 — вознаграждение за привлечение людей
+10 — срочность, давление
+10 — утверждения о выплатах
+5 — шаблонные повторения в группе
+10 — сочетание прибыли и взноса

Индекс ограничен диапазоном 0–100. Низкий: 0–29, средний: 30–59, высокий: 60–100. Наличие предупреждающего контекста снижает оценку. Для высокого риска нужны несколько независимых сигналов.

Это прозрачная эвристическая система, а не обученная вероятностная нейросеть. Индекс 85/100 не означает вероятность мошенничества 85%.

Форматы и ограничения

CSV с заголовками; Telegram JSON с массивом messages и текстом в строке или массивах фрагментов; WhatsApp TXT с распространёнными датами и многострочными сообщениями. OCR использует внешнюю браузерную библиотеку Tesseract.js по запросу и требует интернет; остальные основные функции работают без интернета. Подлинность скриншотов не проверяется. Данные не собираются из закрытых чатов автоматически. Модель может ошибаться на сарказме, отрицаниях и новых схемах.
